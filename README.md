# Netflix Analytics

A team-based data analysis project using the Netflix Titles dataset.

## 📌 Project Overview

This project analyzes Netflix movies and TV shows to discover trends,
patterns, and insights related to content type, release years, countries,
genres, ratings, and other key attributes.

The project is being developed as part of a scholarship training program.

## 🎯 Objectives

- Explore and understand the Netflix dataset
- Clean and prepare the data
- Analyze movies and TV shows
- Identify trends over time
- Analyze content by country, genre, and rating
- Create meaningful visualizations
- Build an interactive Power BI dashboard
- Present clear and actionable insights

## 🛠️ Tools

- Microsoft Excel
- Power BI
- Git & GitHub
